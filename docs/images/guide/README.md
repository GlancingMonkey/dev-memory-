사진의 ID·개수·순위·유사도·시간·토큰은 각 촬영 화면의 관찰값입니다. 새로운 API·DB 대조, 검색 품질 평가나 속도 측정의 결과로 집계하지 않습니다. AI 답변 사진에는 이전부터 저장되어 있던 같은 내용의 sample.py(ID 8)가 출처로 표시됩니다.

키 설정 사진에는 전체 API 키가 포함되지 않습니다. 실제 키를 별도로 읽거나 Git에 저장하지 않았습니다.

기존 11월 18일 Gemini 화면과 실험 원본은 기존 경로에 보존합니다.
