날짜가 있는 문서는 **당시 실제로 확인한 결과**입니다. 새 환경의 실행 방법은 실행 가이드를 따르고, 예전 문서의 ID·순위·응답 시간을 현재의 보장값으로 사용하지 않습니다.

## 문서를 갱신할 때

- 기능 설명은 실제 소스와 일치시킵니다. 예정 기능은 완료 기능과 구분합니다.
- API 변경은 공식 계약에, 실행 방법은 각 가이드에, 실행 결과는 날짜별 검증 기록에 남깁니다.
- 검증 기록에는 기준 커밋·환경·실행 방법·실제 결과·확인하지 않은 범위를 적습니다.
- 예전 실험 산출물을 새 결과로 덮어쓰지 않습니다. 비밀값과 개인 경로가 포함된 로그는 게시하지 않습니다.
