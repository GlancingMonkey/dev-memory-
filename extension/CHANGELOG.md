- 시간 초과·원문 저장 확인 불가는 별도 경고로 안내하고 자동 재전송하지 않음

### 검색
- 이 PC에서 연 프로젝트 위치를 기억해 프로젝트를 닫아도 원본 파일만 바로 열기
- 예전 코드의 원본 위치 한 번 연결, 이동한 프로젝트 재연결, 같은 이름의 여러 프로젝트를 임의로 선택하지 않기
- 원본 경로는 로컬 globalState에만 보관하고 API·DB 저장 필드는 유지
- 사이드바 자연어 검색 (`GET /search`), 순위·id·유사도·파일 위치·줄 번호·문법 색
- 원본 열기 / 들여쓰기 맞춘 삽입 / 복사 / 비교, 원본 없음 미리 표시
- 자세히·간단히 보기, 언어·프로젝트 필터, 결과 기록 복사, 최근 검색어, 지난 검색 복원
- 비슷한 코드 찾기, 키보드 이동, Ctrl+Alt+F

- 평가의 AI 요청도 선택한 개인 키를 사용하고 제공자/서버 기본 키를 표시, 안전하지 않은 전송 주소면 실행 전 중단

- 마크다운·CSV·JSON 내보내기, 예시 질문 파일 만들기, 진행 중 취소

### 검색 범위 (이슈 #38 #39 #40)
- 프로젝트·언어 칩 → `GET /search?project=&language=` 로 DB 에서 먼저 거름, 목록은 `GET /filters`(코드 수·열린 폴더 표시·직접 입력)
- 범위 변경 시 즉시 재검색·늦은 응답 무시·범위 유지, 범위 때문에 0개일 때 조건 풀기 버튼
- 늦은 이전 검색 응답이 최근 검색의 복원 상태를 덮어쓰지 않도록 확장 본체에서도 요청 순서 확인
- 검색 오류·시간 초과 시 새로 작성한 입력이 없으면 실패한 검색어를 입력창에 복원
- 서버가 `filters` 를 돌려주지 않으면 "화면에서만 거름" 경고, AI 답변에 "범위 무시 · 전체 DB" 표시
- 기존 "받은 결과 안에서만 거르는" 선택 상자 제거, `/ask` 오류 detail 객체({code, message}) 표시
