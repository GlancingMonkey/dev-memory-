## [Unreleased]

### 저장
- 선택한 코드 + 메타데이터(프로젝트·상대 경로·언어·함수 이름·줄 번호)를 `POST /snippets` 계약 7개 필드로 전송
- 선택 없이 커서만 두면 그 함수 전체 저장, 함수 이름은 VS Code 코드 구조로 추출 (못 받으면 정규식)
- 저장 중 중복 실행 방지, 시간 초과 안내(자동 재전송 없음), 걸린 시간 기록, 제한 시간 설정
- 확정된 저장 응답 ready / failed / null에 따라 원문 저장과 검색 준비를 구분
- HTTP 503도 원문 저장이 확인된 ID를 알림·저장 기록에 유지
- 시간 초과·원문 저장 확인 불가는 별도 경고로 안내하고 자동 재전송하지 않음
- 과거 pending 기록을 임베딩 미처리로 표시
- 저장 전 함수 이름 확인(설정), 저장 기록, 저장 알림의 "검색에서 확인"

- 원본 열기 / 들여쓰기 맞춘 삽입 / 복사 / 비교, 원본 없음 미리 표시
- 자세히·간단히 보기, 언어·프로젝트 필터, 결과 기록 복사, 최근 검색어, 지난 검색 복원
- 비슷한 코드 찾기, 키보드 이동, Ctrl+Alt+F

### AI 질문 (이슈 #44)
- 검색창 하나로 검색·AI 질문: 끝에 `?` + Enter = AI 질문(입력 중 아이콘·버튼·테두리로 표시), Ctrl+Enter = 항상 AI, Shift+Enter = 항상 검색
- `?` 없이 질문처럼 생긴 검색어는 결과 위에 "AI에게 물어볼까요?" 제안만 (규칙 기반, LLM 호출 없음)
- 검색 예시 / 질문 예시 구분, 최근 검색어에 AI 질문 ✦ 표시, 첫 사용 안내, 설정 `askOnQuestionMark`
- 사람이 실행할 때만 `POST /ask` 전송, 중복 요청 방지, 자동 재전송 없음
- 답변의 [S1] 인용 → 참고 코드 카드 펼치기·이동, 목록에 없는 인용은 열 수 없게 표시
- 생성 중 / 답변 완료 / 근거 부족 / 오류(422·502·503·504·연결) 구분, 질문 유지, 늦게 온 이전 답 무시
- 모델·토큰 사용량·걸린 시간·"전체 DB 대상" 표시, 제한 시간 설정 `askTimeoutSeconds`
- mock 샘플 답변 (`#근거부족`, `#오류` 로 화면 시험), `parseAskResponse` 단위 테스트
- 생성 중 취소(Esc)·경과 초, 한 글자씩 받기(`stream: true`, SSE — 미지원 서버는 한 번에)
- 이어서 묻기(`history` 최근 2개, 최대 3번, 새 대화), 서버 미반영(`history_used` 없음) 안내
- 답변 복사(마크다운), 답변 속 코드 글씨, 인용 안 된 참고 코드 접기
- 👍/👎 피드백(이유 칩·메모, 이 PC 저장) + 명령 "AI 피드백 내보내기"
- 같은 질문은 저장된 답변으로(최근 10개, 다시 생성), 최근 기록에 "답변 저장됨"
- 잘 보이게: 우클릭 맨 위 3개, 함수 위 CodeLens(설정 `codeLens`), 묻기 Ctrl+Alt+A, 패널 제목줄 아이콘, 상태 표시줄 전체 메뉴, 피드백 모아보기 링크, 단축키 안내 카드
- 보낸 뒤 검색창 비우기 (검색어는 요약줄, 질문은 답변 칸에 표시)
- 오늘 AI 사용량(상태 표시줄 ✦ N·토큰), 애매한 질문 경고, 우클릭 "이 코드에 대해 묻기", 답변 단축키(1~9·C·R·F·Esc)
