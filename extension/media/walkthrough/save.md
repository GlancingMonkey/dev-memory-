# 코드 저장하기

1. 프로젝트 폴더를 열고 디스크에 저장된 파일에서 코드 범위를 **선택**합니다.
2. **Ctrl+Alt+S** 또는 우클릭 → **Code Memory: 코드 저장**을 실행합니다.
3. 응답이 올 때까지 기다리고 **저장 기록**에서 ID와 검색 준비 상태를 확인합니다.

선택이 없으면 언어 확장이 제공하는 코드 구조에서 현재 함수를 찾습니다.
자동으로 찾지 못하면 직접 범위를 선택하세요. 함수 이름·파일 경로·줄 번호·언어는 자동으로 수집합니다.

**검색 준비됨**일 때 알림의 **검색에서 확인**으로 바로 찾을 수 있습니다.
**검색 준비 실패**여도 원문과 ID는 남습니다. 시간 초과나 확인 필요 상태에서는 같은 저장을 반복하기 전에 서버 로그·DB를 확인하세요.

mock 모드의 저장은 실제 DB 저장이 아닌 화면 시험입니다.
